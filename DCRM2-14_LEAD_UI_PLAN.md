# DCRM2-14 Lead UI Plan

## Sprint 2 lead interface

The Sprint 2 lead interface is a simple testing prototype.

The form records:

- Campaign
- Name
- Email
- Optional phone number
- Source platform
- Consent status

Supported source platforms:

- Facebook
- Instagram
- LinkedIn

Name and email are required. Phone is optional.

New records are given Pending status and are displayed in the lead queue.

Records are temporarily stored in the browser until the lead queue API is available.

Testing data is used. No live customer data, passwords or API keys are stored.
